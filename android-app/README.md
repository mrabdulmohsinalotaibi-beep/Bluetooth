# Bluetooth ATHAT Android

تطبيق أندرويد أصلي باللغة العربية، يعرض **الأسماء الحقيقية التي يعلنها البلوتوث** ويحدد نوع الجهاز إذا وفر النظام هذه المعلومة.

## المميزات
- اكتشاف Bluetooth Classic (مثل السماعات) وBluetooth Low Energy.
- عرض الأجهزة المقترنة مسبقًا، والأجهزة المكتشفة أثناء الفحص، مع الاسم الفعلي والفئة وحالة الاقتران.
- عدم اختلاق أسماء أو موديلات؛ الأجهزة التي لم تعلن اسمًا تظهر «جهاز غير معروف».
- إجراء الاقتران عبر شاشة تأكيد نظام أندرويد؛ التطبيق لا يتجاوز التحقق أو الموافقة.
- لا إنترنت، لا إرسال لأسماء الأجهزة ولا تخزين دائم للنتائج.

## بناء APK
من مجلد android-app شغل `gradle :app:assembleDebug` باستخدام Android SDK 35 وJDK 17، أو حمّل الأثر `Bluetooth-ATHAT-debug-APK` من GitHub Actions بعد نجاح المهمة.

**تنبيه:** لا يكفي تثبيت الموقع من الشاشة الرئيسية للحصول على هذه الوظائف، يجب تثبيت تطبيق APK الأصلي. ظهور الأجهزة يعتمد على قابلية الاكتشاف وإعلانات الجهاز وصلاحيات النظام. قد تُحجب بعض أجهزة BLE التي تستخدم إعلانات مرتبطة بالموقع بسبب neverForLocation. لا يضمن الاقتران أن الجهاز أصبح مخرج الصوت؛ يتم اختيار مخرج الصوت من إعدادات Android.
